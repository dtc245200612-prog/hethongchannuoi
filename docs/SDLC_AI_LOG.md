# Nhật ký sử dụng AI trong SDLC

| Giai đoạn | Nội dung AI hỗ trợ | Phần sinh viên cần kiểm tra/chỉnh sửa |
|---|---|---|
| Phân tích | Phân rã yêu cầu đàn, chuồng, chăm sóc, vaccine, tăng trưởng, sinh sản, kho, xuất bán, báo cáo | Đối chiếu đề tài và phạm vi bài kiểm tra |
| Thiết kế | Đề xuất ASP.NET Core MVC, SQLite, cookie authentication, role authorization | Kiểm tra quan hệ dữ liệu và quyền người dùng |
| Lập trình | Sinh khung CRUD, dashboard, AI service, prompt repository | Build, sửa lỗi compile, kiểm tra transaction nghiệp vụ |
| Prompt engineering | Tạo V1 → V2 → V3, thêm guardrail và JSON output | Chạy thật với model và ghi nhận response |
| Kiểm thử | Sinh test case cho vaccine, tồn kho, hao hụt, quyền AI | Chạy Test Explorer và bổ sung ảnh minh chứng |
| Review | Kiểm tra key, CSRF, password, quyền, timeout, dữ liệu dài | Xác nhận fix tồn tại trong code |
| Tài liệu | README, hướng dẫn chạy, cấu hình key, test | Cập nhật thông tin nhóm / ảnh minh chứng trước khi nộp |

> Khi nộp bài, nên bổ sung ảnh chụp Visual Studio, Test Explorer, màn hình AI và lịch sử prompt để minh chứng quá trình thực hiện thực tế.
